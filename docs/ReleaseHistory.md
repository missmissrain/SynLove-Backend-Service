# 版本演进与部署边界

## 2026.11 · 2026-11-03

配套 SynLove-Personal-Agent v2.0。发行代码取自家庭服务器实际部署来源，保留低显存 TTS、CPU ASR、Gemma 视觉代理及后台业务兼容改动。

### 配置迁移

保留自己的模型目录、Python 环境、数据库、API 密钥、节点 ID 和证书。不要用示例文件覆盖已有配置。浏览器路径由部署者通过 `PLAYWRIGHT_BROWSERS_PATH` 显式配置，支持 Windows 计划任务账户与交互账户不同的情况。

远程模型只负责生成，时间线与人物关系的个人数据库仍由主程序维护。后台提醒、新闻与结果库属于各自部署，不自动合并到其他用户。

### 验收

接口身份检查与真实推理分别验证。配套核查使用人工文本、语音和人物素材验证远端推理，不以端口监听代替模型成功。并发和故障注入在本机隔离环境进行，不对线上模型施加压测流量。

音频接口增加拒绝请求的有限排空处理，修复 Windows 下错误密钥请求可能触发连接复位的问题。以 32 个并发错误密钥请求验证全部返回 401，并确认随后合法请求仍可用；两项音频服务保持相同实现。

## 后台功能拆分版

将爬虫中心、网页收集、视频理解、定时提醒加入独立后台，增加日程迁移、持久通知和 Hub 出站能力。

## 健康协议与 TTS 修复版

统一 TTS/ASR 的健康协议，修复不带音色描述时默认 CFG 参数不适配的问题。
